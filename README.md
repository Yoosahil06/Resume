# Sahil Gevariya — Technical Portfolio & CV

A responsive, static portfolio site introducing Sahil Gevariya and presenting selected technical projects through an interactive bookshelf.

## Features

- CV-first introduction, education, technical focus, and contact details
- Project bookshelf with animated book selection and detailed project spreads
- Responsive technical-focus cards, project details, and skills
- Reduced-motion support and keyboard-accessible project dialogs

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — layout, responsive styles, bookshelf, and animations
- `script.js` — project data, shelf rendering, and interactions

The project uses plain HTML, CSS, and JavaScript. Google Fonts are loaded from Google Fonts.
