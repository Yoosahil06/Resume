# Sahil Gevariya - Premium Interactive Resume Website

A modern, professional, and highly interactive resume website showcasing the skills and projects of Sahil Gevariya - Game Developer, Animator, IT Enthusiast, CAD Developer, and Backend Engineer.

## 🌟 Features

### Premium Design
- **Modern Color Scheme**: Deep Purple Black (#1A1A2E), Neon Mint (#00FFAB), Inky Blue (#16213E)
- **Glassmorphism Effects**: Translucent cards with backdrop blur
- **Gradient Backgrounds**: Dynamic color transitions throughout
- **Responsive Design**: Optimized for all devices and screen sizes

### Interactive Elements
- **Animated Skills Section**: 
  - Progress bars with percentage indicators
  - Expandable skill cards with detailed information
  - Category-based filtering system
  - Hover effects and micro-interactions
- **Floating Icons**: Animated technology icons in hero section
- **Smooth Scrolling**: Seamless navigation between sections
- **Typing Effect**: Dynamic text animation in hero section

### Professional Sections
1. **Hero Section**: Dynamic introduction with animated elements
2. **About Me**: Professional summary with highlighted expertise areas
3. **Education**: Timeline-style educational journey
4. **Skills**: Highly interactive showcase with filtering and animations
5. **Projects**: Featured work with hover effects and project details
6. **Contact**: Professional contact form with social links

### Technical Features
- **Pure HTML5, CSS3, JavaScript**: No framework dependencies for maximum performance
- **Intersection Observer API**: Efficient scroll-triggered animations
- **CSS Grid & Flexbox**: Modern layout techniques
- **Custom Animations**: Smooth transitions and micro-interactions
- **Accessibility**: Focus states and semantic HTML
- **Performance Optimized**: Debounced scroll events and resource preloading

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for development)

### Installation
1. Clone or download the repository
2. Open `index.html` in your web browser
3. For development, use a local server:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js
   npx serve .
   
   # Using PHP
   php -S localhost:8000
   ```

### File Structure
```
Resume/
├── index.html          # Main HTML structure
├── styles.css          # Complete CSS styling and animations
├── script.js           # Interactive functionality
└── README.md           # Project documentation
```
